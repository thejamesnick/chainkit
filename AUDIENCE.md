# ChainKit — Who To Show This To

Who will get it immediately, why they care, and how to reach them.

---

## 1. Solana Hackathon Builders

**Why they care:**
They have 48 hours. They don't want to spend half of it wiring up RPC connections, normalizing API responses, and reading 5 different docs. ChainKit is the tool they wish existed every hackathon.

**Where to reach them:**
- Colosseum hackathons (colosseum.org)
- Solana Foundation hackathons
- Superteam bounties and builds
- #dev channels in Solana Discord

**How to show it:**
Post a before/after — "here's what setting up Solana data used to look like, here's ChainKit." Keep it short, show the code diff.

---

## 2. AI Agent Builders

**Why they care:**
Anyone building autonomous agents that touch Solana — trading bots, portfolio agents, DeFi assistants — needs a clean programmatic interface to the chain. ChainKit is the blockchain layer they drop into their agent codebase instead of wiring up 5 APIs manually.

**Where to reach them:**
- AI agent communities on Twitter/X
- LangChain, Vercel AI SDK Discord servers
- Solana AI hackathons (these are happening now)
- GitHub — search for Solana + LangChain repos, reach out directly

**How to show it:**
Show a real agent tool definition using ChainKit. 10 lines vs what it looked like before.

---

## 3. Solana Ecosystem — Superteam & Foundation

**Why they care:**
They actively fund and promote tooling that reduces friction for builders in the ecosystem. A well-documented open source SDK that makes Solana easier to build on is exactly what they want more of.

**Where to reach them:**
- Superteam (superteam.fun) — apply for a grant or just post in their community
- Solana Foundation developer grants program
- Solana tech Twitter/X — tag @solana, @SolanaFndn

**How to show it:**
Lead with the problem statement from PROBLEM.md. They've heard the fragmentation complaint a hundred times — show you solved it.

---

## 4. Indie Devs & Hack Series Builders

**Why they care:**
Developers building their own side projects, hack series, or weekend builds see ChainKit and immediately think "I could have used this last week." They become users and word-of-mouth fast.

**Where to reach them:**
- Twitter/X — #buildinpublic, #SolanaDev, #web3dev
- Dev.to, Hashnode — write a short post about building it
- GitHub — good README gets organic discovery

**How to show it:**
Build in public. Post progress. Show the demos working. Devs follow builders.

---

## 5. Developer Tool Investors

**Why they care:**
Solana infrastructure and tooling is fundable. A clean SDK with real adoption signals — GitHub stars, npm downloads, projects using it — is a fundable product if you want to go that route.

**Where to reach them:**
- Solana Ventures
- Multicoin Capital
- Colosseum accelerator
- Superteam grants (smaller, faster)

**How to show it:**
Don't pitch too early. Get adoption first — even 10 real projects using ChainKit is more convincing than any deck.

---

## 6. Developers Who've Felt The Pain

**Why they care:**
Anyone who's copy-pasted Helius boilerplate three times, fought with `@solana/web3.js` response shapes, or spent a day wiring up Jupiter just to get a swap quote — they get it instantly. No selling needed.

**Where to reach them:**
- Solana Discord — #dev-support, #tooling channels
- Twitter/X replies — find threads where devs complain about Solana DX
- Reddit — r/solana, r/solanadev

**How to show it:**
Find a complaint tweet about Solana developer experience. Reply with ChainKit. Let the code speak.

---

## Launch Sequence

1. Build the Wallet Inspector UI demo — get something visual working
2. Post a before/after code comparison on Twitter/X
3. Share in Solana Discord dev channels
4. Submit to Superteam for visibility
5. Write a short dev.to / Hashnode post — "I got tired of wiring up 5 Solana APIs so I built this"
6. Open source on GitHub with a solid README
7. npm publish — let organic discovery do its thing
